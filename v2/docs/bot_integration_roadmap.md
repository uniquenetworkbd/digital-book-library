> Status: structure created; the complete 60-feature bot specification will be added from the supplied v2.0 master documentation in the next phase.

- Client-side bot engine
- Rule engine and command parser
- No new backend server

## Compatibility

All bot functionality must remain isolated from the v1.0 production surface until v2.0 audit and migration approval.
