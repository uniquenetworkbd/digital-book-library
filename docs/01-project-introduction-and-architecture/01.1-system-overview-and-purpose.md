# 1.1 সিস্টেম ওভারভিউ ও উদ্দেশ্য

## রোডম্যাপ ডকুমেন্টেশন: অধ্যায় ১

# ১. প্রজেক্ট পরিচিতি ও আর্কিটেকচার ডিজাইন

## ১.১ সিস্টেম ওভারভিউ ও উদ্দেশ্য

 * **মূল লক্ষ্য:** GitHub Pages-এর স্ট্যাটিক হোস্টিং ব্যবহার করে সম্পূর্ণ ব্রাউজার-বেইজড (Client-side) একটি ডিজিটাল বুক লাইব্রেরি এবং বুক অথরিং (বই লেখার) প্ল্যাটফর্ম তৈরি করা। এখানে কোনো এক্সটার্নাল সার্ভার, পিএইচপি বা ট্রেডিশনাল ডাটাবেস ব্যবহার করা হবে না।
 * **প্রধান উদ্দেশ্যসমূহ:**
   * ব্যবহারকারীরা প্ল্যাটফর্মে এসে বিনামূল্যে বই পড়তে পারবেন এবং ক্যাটাগরি অনুযায়ী বই সার্চ বা ফিল্টার করতে পারবেন।
   * লেখকরা কোনো ঝামেলা ছাড়াই ওয়েবসাইট থেকেই নির্দিষ্ট টেমপ্লেট সিলেক্ট করে নতুন বই লিখতে পারবেন।
   * ব্রাউজারের নিজস্ব মেমোরি (IndexedDB) ব্যবহার করে লেখার সময় রিয়াল-টাইম অটো-সেভ নিশ্চিত করা, যাতে হঠাৎ পেজ রিফ্রেশ হলেও ডাটা হারিয়ে না যায়।
   * কাজ শেষে সরাসরি GitHub-এর মাধ্যমে বইটি লাইব্রেরিতে প্রকাশ (Publish) করার ব্যবস্থা রাখা।

## ১.২ কমপ্লিট ফোল্ডার ও ফাইল স্ট্রাকচার

প্রজেক্টটি নিখুঁতভাবে পরিচালনার জন্য ফাইল ও ফোল্ডারগুলোর বিন্যাস নিচে দেওয়া হলো:

```text
digital-book-library/
├── index.html                  # হোমপেজ ও লাইব্রেরি ইন্টারফেস (বই তালিকা ও ফিল্টার)
├── reader.html                 # ই-বুক রিডার পেজ (বই পড়ার ইন্টারফেস)
├── creator.html                # বুক এডিটর ও রাইটিং পেজ (নতুন বই লেখার ইন্টারফেস)
├── README.md                   # প্রজেক্ট ডিরেক্টরি ও গাইডবুক বিবরণ
├── assets/
│   ├── css/
│   │   ├── main.css            # মূল স্টাইলশিট (লাইব্রেরি ও গ্লোবাল ডিজাইন)
│   │   ├── reader.css          # রিডার পেজের কাস্টম স্টাইল
│   │   └── editor.css          # এডিটর পেজের কাস্টম স্টাইল
│   ├── js/
│   │   ├── app.js              # লাইব্রেরি ডেটা ফেচ ও ফিল্টারিং লজিক
│   │   ├── reader.js           # বুক রেন্ডারিং ও পেজ টার্নিং লজিক
│   │   ├── editor.js           # টেমপ্লেট হ্যান্ডলিং ও এডিটর লজিক
│   │   └── db.js               # IndexedDB এবং অটো-সেভ ম্যানেজমেন্ট লজিক
│   └── templates/
│       ├── novel.json          # উপন্যাসের প্রি-সেট কাঠামো (অধ্যায় ভিত্তিক)
│       └── technical.json      # টেকনিক্যাল বইয়ের প্রি-সেট কাঠামো
└── data/
    ├── catalog.json            # লাইব্রেরিতে প্রকাশিত সমস্ত বইয়ের ক্যাটালগ তালিকা
    └── books/                  # প্রকাশিত বইগুলোর বিস্তারিত JSON ফাইলসমূহ
```

## ১.৩ টেকনোলজি স্ট্যাক সিলেকশন

এই প্ল্যাটফর্মটি তৈরি করার জন্য যে প্রযুক্তিগুলো নির্বাচন করা হয়েছে:

 * **হোস্টিং ও ডেপ্লয়মেন্ট:** GitHub Pages (সম্পূর্ণ ফ্রি এবং রিলায়েবল স্ট্যাটিক হোস্টিং)।
 * **ইউজার ইন্টারফেস (UI):** HTML5, CSS3 (রেসপন্সিভ ডিজাইনের জন্য), এবং Vanilla JavaScript (ES6+ মডিউল), যা কোনো ভারী ফ্রেমওয়ার্ক ছাড়াই দ্রুত গতিতে কাজ করবে।
 * **লোকাল স্টোরেজ ও ডেটাবেস:** ব্রাউজার-বেইজড IndexedDB (বইয়ের খসড়া বা ড্রাফট এবং বড় টেক্সট লোকালি সেভ করার জন্য)।
 * **ডেটা এক্সচেঞ্জ ফরম্যাট:** JSON (বইয়ের মেটাডেটা, ক্যাটালগ এবং কন্টেন্ট সংরক্ষণের জন্য)।
