# 4.1 টেমপ্লেট ইঞ্জিন (ক্যাটাগরি অনুযায়ী প্রি-সেট স্ট্রাকচার জেনারেশন)

লেখক যখন নতুন বই লেখা শুরু করবেন, তখন তাকে শূন্য থেকে সবকিছু সাজাতে হবে না। `assets/templates/` ফোল্ডারে থাকা প্রি-সেট JSON ফাইলগুলোর মাধ্যমে টেমপ্লেট ইঞ্জিন স্বয়ংক্রিয়ভাবে বইয়ের কাঠামো তৈরি করে দেবে।

## মূল ফিচারসমূহ

### ক্যাটাগরি সিলেকশন ড্রপডাউন

এডিটর পেজে প্রবেশ করার পর লেখক ক্যাটাগরি বা জেনার (যেমন: Novel, Technical, Research) সিলেক্ট করার অপশন পাবেন।

### অটো-স্ট্রাকচার জেনারেশন (Template Engine)

লেখক ক্যাটাগরি সিলেক্ট করার সাথে সাথেই ইঞ্জিন ব্যাকগ্রাউন্ড থেকে নির্দিষ্ট টেমপ্লেট (যেমন: `novel.json`) লোড করে এডিটরের ভেতরে অধ্যায়গুলোর একটি কঙ্কাল বা ট্রি-ভিউ (যেমন: প্রাক-কথা, অধ্যায় ১, অধ্যায় ২, উপসংহার) তৈরি করে দেবে।
