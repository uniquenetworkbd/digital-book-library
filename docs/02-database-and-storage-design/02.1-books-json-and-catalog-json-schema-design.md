# 2.1 books.json ও catalog.json স্কিমা ডিজাইন

## রোডম্যাপ ডকুমেন্টেশন: অধ্যায় ২

# ২. ডেটাবেস ও স্টোরেজ ডিজাইন

যেহেতু এই প্ল্যাটফর্মটিতে কোনো এক্সটার্নাল সার্ভার-সাইড ডাটাবেস (যেমন: MySQL, PostgreSQL) ব্যবহার করা হচ্ছে না, তাই সম্পূর্ণ প্রজেক্টের ডেটা ম্যানেজমেন্ট দুই ভাগে বিভক্ত করা হয়েছে:

- **পাবলিক ডেটা লেয়ার (catalog.json ও বইয়ের JSON ফাইল):** যা GitHub রিপোজিটরিতে স্ট্যাটিক ফাইল হিসেবে সংরক্ষিত থাকবে এবং লাইব্রেরির সবাই দেখতে পাবে।
- **লোকাল স্টোরেজ লেয়ার (IndexedDB):** লেখক যখন ব্রাউজারে বসে নতুন বই লিখবেন, তখন তার খসড়া বা ড্রাফট নিরাপদে এবং স্বয়ংক্রিয়ভাবে সেভ করার জন্য।

## ২.১ books.json এবং catalog.json স্কিমা ডিজাইন

লাইব্রেরির মূল হোমপেজে সমস্ত প্রকাশিত বইয়ের তালিকা দেখানোর জন্য `data/catalog.json` ফাইল ব্যবহার করা হবে। আর প্রতিটি বইয়ের ভেতরের অধ্যায় ও কন্টেন্ট সংরক্ষণের জন্য `data/books/` ফোল্ডারের ভেতরে আলাদা আলাদা JSON ফাইল থাকবে।

### ১. data/catalog.json (বইয়ের ক্যাটালগ স্কিমা)

এই ফাইলে প্ল্যাটফর্মের সমস্ত প্রকাশিত বইয়ের মেটাডেটা বা পরিচিতি সংরক্ষিত থাকবে:

```json
[
  {
    "id": "book-001",
    "title": "বাংলা সাহিত্যের ইতিহাস",
    "author": "রাফসান জামিল",
    "category": "Literature",
    "coverImage": "assets/covers/book-001.jpg",
    "filePath": "data/books/book-001.json",
    "publishDate": "2026-10-21"
  },
  {
    "id": "book-002",
    "title": "ডেটা স্ট্রাকচার ও অ্যালগরিদম",
    "author": "টেক টিম",
    "category": "Technical",
    "coverImage": "assets/covers/book-002.jpg",
    "filePath": "data/books/book-002.json",
    "publishDate": "2026-10-21"
  }
]
```

### ২. data/books/book-001.json (নির্দিষ্ট বইয়ের কন্টেন্ট স্কিমা)

প্রতিটি বইয়ের মূল লেখা বা অধ্যায়গুলো এই স্ট্রাকচারে সংরক্ষিত হবে:

```json
{
  "bookId": "book-001",
  "title": "বাংলা সাহিত্যের ইতিহাস",
  "author": "রাফসান জামিল",
  "category": "Literature",
  "chapters": [
    {
      "chapterId": 1,
      "title": "প্রাক-কথা ও ভূমিকা",
      "content": "এখানে প্রথম অধ্যায়ের মূল টেক্সট বা মার্কডাউন ফরম্যাটের কন্টেন্ট থাকবে..."
    },
    {
      "chapterId": 2,
      "title": "প্রথম অধ্যায়: প্রাচীন যুগ",
      "content": "চর্যাপদ ও প্রাচীন যুগের সাহিত্য নিয়ে বিস্তারিত আলোচনা..."
    }
  ]
}
```
