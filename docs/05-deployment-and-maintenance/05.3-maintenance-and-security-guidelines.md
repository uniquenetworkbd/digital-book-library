# 5.3 মেইনটেন্যান্স ও সিকিউরিটি গাইডলাইন

## ব্যাকআপ

লেখকের লোকাল ড্রাফটগুলো ব্রাউজারের IndexedDB-তে সংরক্ষিত থাকায় ব্রাউজার ক্যাশ পরিষ্কার করার আগে ড্রাফটগুলো JSON ফাইলে এক্সপোর্ট করে ব্যাকআপ রাখা নিরাপদ।

## কপিরাইট ও মডারেশন

পাবলিক লাইব্রেরিতে আপলোড করা কন্টেন্টগুলো যেন কপিরাইট আইন মেনে চলে এবং ক্ষতিকারক কোড বা স্ক্রিপ্ট মুক্ত থাকে, সে বিষয়ে সতর্ক থাকা।
