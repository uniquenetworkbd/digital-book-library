# 5.2 GitHub API ব্যবহার করে বা ম্যানুয়াল পদ্ধতিতে ডিরেক্ট পাবলিশিং ওয়ার্কফ্লো

যেহেতু প্ল্যাটফর্মে লেখক কর্তৃক নতুন বই তৈরির পর তা লাইব্রেরিতে যুক্ত করার প্রয়োজন হয়, তাই স্ট্যাটিক সাইটে নতুন বই পাবলিশ করার জন্য নিচের ওয়ার্কফ্লো অনুসরণ করা হবে:

## ১. ম্যানুয়াল পাবলিশিং পদ্ধতি (সবচেয়ে সহজ)

এডিটর মডিউল থেকে লেখক যখন লেখা শেষ করে **"Export Book"** বা **"Download JSON"** করবেন, তখন একটি `.json` ফাইল ডাউনলোড হবে।

লেখক সেই ফাইলটি GitHub Repository-র `data/books/` ফোল্ডারে আপলোড করবেন।

এরপর `data/catalog.json` ফাইলে নতুন বইয়ের মেটাডেটা (আইডি, নাম, লেখক, ফাইলের পাথ) যুক্ত করে কমিট করলেই বইটি স্বয়ংক্রিয়ভাবে লাইব্রেরিতে যোগ হয়ে যাবে।

## ২. GitHub API বা Personal Access Token (PAT) ভিত্তিক অটোমেটেড পদ্ধতি (উন্নত)

এডিটর পেজে একটি ডেডিকেটেড **"Publish Settings"** প্যানেল থাকবে, যেখানে লেখক তার GitHub Personal Access Token ইনপুট দিতে পারবেন।

লেখক যখন এডিটর থেকে সরাসরি **"Publish"** বাটনে ক্লিক করবেন, তখন ব্যাকগ্রাউন্ডে GitHub-এর অফিশিয়াল API কল হবে।

এই API স্বয়ংক্রিয়ভাবে লেখকের রিপোজিটরির `data/books/` ফোল্ডারে নতুন বইয়ের ফাইল এবং `data/catalog.json`-এ তার ক্যাটালগ এন্ট্রি পুশ করে দেবে। এর ফলে কোনো কোডিং ছাড়াই সরাসরি ওয়েবসাইট থেকেই নতুন বই পাবলিশ করা সম্ভব হবে।
