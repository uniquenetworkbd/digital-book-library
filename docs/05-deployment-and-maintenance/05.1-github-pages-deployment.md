# 5.1 GitHub Pages-এ লাইভ করার নিয়ম

আমাদের প্রজেক্টটি কোনো এক্সটার্নাল হোস্টিং ছাড়াই সম্পূর্ণ ফ্রিতে GitHub-এর বিল্ট-ইন হোস্টিং ফিচারের মাধ্যমে লাইভ করা হবে।

## ডিপ্লয়মেন্ট স্টেপসমূহ

### কোড পুশ করা (Push to Main Branch)

প্রজেক্টের সমস্ত ফাইল (`index.html`, `reader.html`, `creator.html`, `assets/`, `data/`) সঠিকভাবে সাজিয়ে আপনার GitHub Repository-র `main` বা `master` ব্রান্সে আপলোড বা কমিট (Commit) করুন।

### Pages সেটিংস কনফিগারেশন

Repository-র ওপরের মেনু থেকে **Settings** ট্যাবে যান।

বামপাশের সাইডবার থেকে **Pages** অপশনে ক্লিক করুন।

**Build and deployment** সেকশনের অধীনে:

- **Source:** `Deploy from a branch` সিলেক্ট করুন।
- **Branch:** `main` এবং ফোল্ডার `/ (root)` সিলেক্ট করে **Save** বাটনে ক্লিক করুন।

### লাইভ URL প্রাপ্তি

১-২ মিনিট অপেক্ষা করার পর ওই একই পেজে একটি অফিশিয়াল লাইভ লিংক দেখতে পাবেন (যেমন: `https://your-username.github.io/digital-book-library/`)। এই লিংকে প্রবেশ করলেই আপনার সম্পূর্ণ ডিজিটাল লাইব্রেরি ওয়েবসাইটটি সবার জন্য সচল দেখতে পাবেন।
